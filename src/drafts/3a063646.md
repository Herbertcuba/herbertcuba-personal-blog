On August 1, 2026, [Om Patel shared the July dashboard](https://x.com/om_patel5/status/2083401185172541449) from Claude Code, Anthropic's coding agent. His $200 Max plan had carried 6.16 billion tokens. The dashboard priced the same usage at $7,470.35 under API list rates, 37.4 times the subscription fee.

Patel did not owe $7,470, and the figure did not reveal Anthropic's compute cost. It revealed something more useful to an engineer: flat pricing had removed the feedback signal from an expensive pattern of behavior.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>The surprise is not a hidden bill. It is the workflow cost that a flat fee makes easy to ignore.</p></div>

## The meter is mostly reading

When an agent takes another turn, the latest instruction can arrive with system rules, tool definitions, files, and prior conversation. Patel's cache reads and writes represented 86.2% of the dashboard's API-equivalent value. [Prompt caching](https://docs.anthropic.com/en/docs/about-claude/pricing) can make later reads of a stable prefix cheaper; it does not remove that input from the request.

On one instrumented day, AI practitioner [Nate B. Jones recorded](https://www.youtube.com/watch?v=Y8vAQ1FgNbM) 3.77 billion tokens across 143 Codex threads. Of those, 3.59 billion—95.2%, or almost 96%—were reused input. That is one operator's workload, not an industry benchmark, and Jones sells a context framework. Separately, the team behind [Manus, a production AI agent, reported](https://manus.im/blog/Context-Engineering-for-AI-Agents-Lessons-from-Building-Manus) an input-to-output ratio near 100:1 in 2025. That supports input dominance, not the precise reuse percentage.

Context hygiene means choosing what enters the next request. Carry forward constraints, final decisions, and tested artifacts; retire exploratory dialogue after it has done its job. The aim is enough relevant state, not the shortest possible prompt.

Quality matters too. The peer-reviewed 2024 study [*Lost in the Middle*](https://aclanthology.org/2024.tacl-1.9/) found that models retrieved relevant information less reliably when it appeared inside a long input. Open a new thread for unrelated work, search before loading whole files, keep stable instructions together for caching, and cap output. Claude Code's [automatic compaction](https://code.claude.com/docs/en/costs) helps near context limits, but engineers should decide what must survive. When broad context is itself the task, prune cautiously.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Agent economics live largely on the input side. The controllable variable is what earns another pass through the model.</p></div>

## Measure the work that survives review

Direct API billing makes token traffic harder to ignore. A subscription does not, but it need not prevent learning. Choose one repeated task and define acceptance before the trial: tests pass, requirements are met, and a reviewer approves.

Alternate baseline runs that retain accumulated history with runs that receive curated artifacts. Record uncached input, cache reads and writes, output, latency, retries, and review time. Use metered API traffic or apply the same price sheet to both variants.

Then calculate cost per accepted result: total measured trial cost divided by accepted outputs. Token savings that create rework are a failure. A curated run improves the system only if cost falls while acceptance holds.

Patel did not receive a $7,470 bill. He received a warning about a skill that flat pricing gives us little incentive to practice. Learn how much context accepted work actually needs before price or limits make the decision for you.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Optimize the cost of approved outcomes, not token counts alone. Context efficiency matters only when quality survives.</p></div>
