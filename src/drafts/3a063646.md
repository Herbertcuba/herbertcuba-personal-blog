A $200 Claude subscription just generated $7,470 worth of API calls. One month, one user, 6.16 trillion tokens across 36,881 responses. Run the math on a million subscribers doing the same thing, and Anthropic's land grab starts to look like a controlled fire.

The numbers come from Om Patel, a Max subscriber who ran claude-cost over his own July usage and posted the output. I tried to poke holes in it. The arithmetic holds.

## One user, 37x subsidy

Patel paid $200 and consumed $7,470 in list-price API value.
<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>A $200 Max plan produced $7,470 of hypothetical API spend in one month. Cache reads did half the damage, which says this user is running heavy agentic workflows, not chatting.</p></div>

The breakdown tells you what kind of user this is. Cache reads: $3,596, nearly half the total. Cache writes: $2,842. Actual output tokens: $1,016, only 13.6 percent. This is someone running CLI coding agents all day, where every response drags a mountain of context behind it. CLI tools burn somewhere between 500 and 1,000 input tokens per output token. A custom toolchain runs closer to 1:1.5.

The model split is the other tell. Claude Fable 5 ate $2,794, Opus 4.8 took $2,330, Opus 5 another $2,141. Top-tier models, all month, on a flat plan.

I think this is the part most readers skip past. The subsidy is 37x at list price. List price is set for enterprise builders whose margins absorb it. Anthropic's actual compute cost is lower, and I don't know by how much. Nobody outside the company does. But even at a generous internal discount, this user is deeply underwater.

## The mobile phone plan logic

Most subscribers never come close to this. That is the entire business model.
<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Subscriptions price for the average user and lose on the outliers. Light users pay for power users, the same way your phone plan works. The power user is not the plan's customer. The power user is the plan's marketing.</p></div>

Patel's framing is worth taking seriously: AI subscriptions work like mobile plans. Most people never hit their limits. They pay for the ones who do. The light user subsidizes the agent-running developer who treats a $200 plan as an all-you-can-eat GPU buffet.

My take: this is also a land grab. The whole industry is burning investor money to lock in users now and postponing profitability to later. Cheap consumer AI is customer acquisition. Enterprise API margins are what pay for it.

## What a million subscribers cost

Now scale it. This is where the arithmetic gets uncomfortable.
<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>If every Max subscriber maxed out like Patel, six months of one million subscriptions would bring in $1.2 billion against $44.8 billion in API-list value. They do not all max out. But even a few percent of power users is a real burn rate.</p></div>

Three months of Patel: $600 paid, roughly $22,410 in API value consumed. Call it $21,810 in discount per power user per quarter.

A million Max subscribers over six months: $1.2 billion in revenue against $44.8 billion in list-price value, a $43.6 billion gap. That number is fiction, because most users are light. But flip it around and it gets real fast. If only 5 percent of a million subscribers run agents like Patel, that is 50,000 users each consuming $44,820 of list value per half year. About $2.2 billion in list-price subsidy, from 5 percent of the base.

I think the honest read is this: list price overstates the loss, light users understate it, and the truth sits somewhere Anthropic is not publishing. The enterprise customers paying full API rates are funding the consumer subsidy whether they know it or not.

Cheap AI was never cheap. Somebody else is paying, and the invoice is due later.
