A $200 Claude subscription just generated $7,470 worth of API calls. A developer named Om Patel ran his own July usage through a cost tool and posted the screenshot on X yesterday.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>One Max subscriber burned $7,470 in list-price API value on a $200 plan. Three calculations show what that gap means: 37x this month, about $21,800 saved over a quarter, and a $43.6 billion ceiling case that says more about the land grab than about any real loss.</p></div>

I tried to poke holes in it. The arithmetic holds.

## What $7,470 of usage looks like

Patel ran a tool called claude-cost over his July 2026 usage. One month, one user, 6.16 billion tokens across 36,881 responses.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>86 percent of the bill is cache operations. Actual generation is only 13.6 percent. The usage is real, and the math checks against Anthropic's public price sheet.</p></div>

Cache reads: $3,596, nearly half the total. Cache writes: $2,842. Actual output tokens: $1,016, only 13.6 percent. 86 percent of the money is cache operations, the agent re-reading context it already saw.

I think the shape of the bill says more than the size of it. An agentic coding tool re-reads your files, your history, and its own instructions thousands of times a day, so the context bill dwarfs the generation bill. Patel points out that CLI tools burn somewhere between 500 and 1,000 input tokens per output token, while a custom toolchain that feeds context directly runs closer to 1:1.5. Treat those ratios as his field observation. His own screenshot shows the shape: 186 tokens consumed for every one generated.

Per model: Claude Fable 5 ate $2,794, Opus 4.8 took $2,330, Opus 5 another $2,141.

I checked the math against Anthropic's published prices. Cache reads run $0.50 per million tokens on Opus and $1 on Fable 5. The screenshot's reads span both models, so the blended rate lands around $0.61 per million, and 5.88 billion cached tokens at that blend sit right on the $3,596 line item. The number is real. On the last day of July alone, $88.85.

## Three calculations

Three ways to run the same gap, each one zooming out a step.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>37x this month. About $21,800 of implied discount over a quarter. And a $43.6 billion ceiling case for a million maxed-out subscribers, which collapses to a small fraction of that the moment you assume people behave like people.</p></div>

One. This month, the subsidy is 37x at list price. Two hundred dollars paid, $7,470 of metered value consumed.

Two. Run that for a quarter. Three months of Patel: $600 paid, roughly $22,410 in API value consumed. Call it $21,810 in discount. For a solo developer, that is a salary. I think this second number is the one that should worry Anthropic, because it repeats every quarter for every heavy user.

Three. Scale it. A million Max subscribers over six months: $1.2 billion in revenue against $44.8 billion in list-price value, a $43.6 billion gap.

That number is fiction, and I want to be precise about why. Most users are light. Anthropic caps usage with rolling five-hour windows and weekly limits it can tighten at will. And list price overstates cost, because the API sticker is retail, set for enterprises building products on top of Claude. Patel himself says it: what serving him actually costs Anthropic in compute is far lower. How much lower, I don't know. Nobody outside the company does. Epoch AI's work on frontier labs suggests compute eats roughly two thirds of revenue, which would put the true cost of Patel's month in the low thousands. A real subsidy, sized nothing like $7,470.

## Who pays for cheap AI

The gap has to be paid by someone.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Enterprise API margins fund the consumer discount. Subscriptions work like unlimited mobile data, where light users cover the heavy ones. And the whole industry is burning investor money to lock you in first and figure out profitability later.</p></div>

My take: the gap between $200 and $7,470 is the business model. API prices carry enterprise margins, and those margins cross-subsidize the consumer plans. Subscriptions are priced like unlimited mobile data, where most people never touch their limits and their fees cover the ones who do.

Meanwhile the land grab is funded. Anthropic's run-rate went from $9 billion at the end of 2025 to $47 billion this May, with $95 billion raised along the way. Ed Zitron's reporting shows the same pattern everywhere: hyperscalers sinking over $1.3 trillion into generative AI through 2026. Investor money goes in, locked-in users come out. Profitability is a promise dated later.

I think of the burning oil derrick in There Will Be Blood. A fire you can size and budget is a strategy. Anthropic can point at this one and show the meter.

We have seen how it ends. GitHub Copilot let power users burn 25 times their subscription fee, then switched to token billing, and the user revolt was immediate. I think the meter comes for Claude Max too, eventually. Cheap AI was never cheap. Somebody else is paying, and the invoice is due later.
