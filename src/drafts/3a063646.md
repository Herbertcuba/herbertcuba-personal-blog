On August 1, 2026, developer [Om Patel](https://x.com/om_patel5/status/2083401185172541449) shared a [Claude Code](https://code.claude.com/docs/en/costs) usage screen. Claude Code is Anthropic’s coding agent; Patel used its $200 Max plan. The screen showed 6.16 billion processed tokens and $7,470.35 at standard API list prices, 37.4 times his fee.

That was neither his bill nor Anthropic’s compute cost. It was a retail-price translation of metered activity. Still, it exposed the operating habit hidden by a flat fee: huge usage feels free when the meter never reaches the buyer.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Patel’s $200 subscription concealed activity valued at $7,470 under standard API prices.</p></div>

## The traffic is mostly old input

An agent receives more than your latest request. Each call may carry system instructions, conversation history, tool definitions, files, and results. [Prompt caching](https://docs.anthropic.com/en/docs/about-claude/pricing) reuses computation for an identical prefix. Anthropic prices a cache read at one-tenth of ordinary input, while charging separately for cache writes.

Repetition still compounds. Patel’s screen attributed $6,440.24, or 86.2 percent of the estimate, to cache reads and writes. Separately, AI practitioner [Nate B. Jones](https://www.youtube.com/watch?v=Y8vAQ1FgNbM) measured 3.77 billion tokens across 143 coding threads in one day; 3.59 billion were reused input, almost 96 percent. One workspace cannot establish an industry-wide rate. It nevertheless shows where one heavy workflow’s volume went.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Agentic coding can spend far more token traffic rebuilding working state than generating new output.</p></div>

## Long context charges twice

Cost is only half the problem. Long threads bury useful evidence among stale attempts, duplicate files, and noisy tool output. [“Lost in the Middle,”](https://aclanthology.org/2024.tacl-1.9/) a peer-reviewed 2024 study, found that models often retrieve relevant information less reliably when it appears inside a long input. More context can therefore raise spend while making needed evidence harder to recover.

[Automatic compaction](https://code.claude.com/docs/en/costs) summarizes history as the context window fills. That helps, but the summary cannot anticipate every fact the next step needs. Engineers must curate working state themselves: split unrelated jobs, save accepted decisions and constraints in a compact artifact, fetch files on demand, cap verbose outputs, and keep stable instructions first for caching.

That practice is [context hygiene](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents): deciding what enters the model’s working state, what stays, and what must be retrieved again.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Clean context cuts repeated input while protecting the model’s limited attention.</p></div>

## Price accepted work

Flat-rate access gives engineers room to learn before inefficient turns become charges. Run representative tasks through API billing for one week, with acceptance tests fixed beforehand. Record fresh input, cache reads, cache writes, output, and whether each result passes.

Calculate cost per accepted result: measured API spend divided by outputs that pass. Compare workflows on that figure alongside latency and quality. A cheaper run that fails more often is no gain. A smaller context that preserves acceptance is.

This makes context engineering an operating discipline. If subscriptions tighten or billing moves toward usage, teams that control working state will know their unit economics. Flat rates offer a temporary chance to learn efficiency before waste appears on the invoice.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Measure spend per accepted result before repricing.</p></div>
