$200 bought developer Om Patel a month of Claude Max. His July 2026 dashboard put the same activity at $7,470.35 when priced at standard API rates: 37.4 times the subscription. The activity came from Claude Code, Anthropic’s terminal coding agent.

That is not Patel’s invoice, Anthropic’s compute cost, or proof of a $7,270 loss. Anthropic says Claude Code’s displayed dollar figure prices the same usage at API rates; Max subscribers are not charged it. But the dashboard reveals an engineering behavior that subscriptions make easy to ignore.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>The $7,470 number is not a bill. It warns that a subscription can hide inefficient token use until token pricing arrives.</p></div>

## The past is the expensive part

Patel’s dashboard recorded 6.16 billion tokens. Cache reads and writes accounted for $6,440.24, or 86.2% of that total; fresh input cost only $14.14. Prompt caching makes unchanged input cheaper: Anthropic prices a cache hit at 10% of ordinary input. But cheaper repetition is still repetition.

Agentic coding tools repeatedly send system instructions, tool definitions, conversation history, files, and prior tool results with the latest request. In one instrumented Codex workday, practitioner Nate B. Jones reported 3.59 billion reused input tokens out of 3.77 billion: 95.2%. That is one workspace, not an industry average, but it exposes the mechanism.

The risk extends beyond cost. The 2024 peer reviewed study Lost in the Middle found that models retrieve relevant information less reliably when it sits inside long inputs. More context can therefore increase the chance that the useful instruction is present but effectively buried.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>The dominant traffic can be old context, discounted by caching but still carried forward, charged, and searched by the model.</p></div>

## Context hygiene is production engineering

Good context hygiene gives the model enough evidence to do the job without carrying the whole record. Separate unrelated work into clean threads. Replace completed discussion with a brief record of decisions, constraints, and remaining questions. Retrieve only relevant files, cap noisy tool output, and keep stable instructions together so caching can work.

Automatic compaction summarizes a long thread near its limit, but remains lossy because the tool decides what survives. Deliberate summaries let the team preserve the evidence behind decisions and the checks still required before more detail accumulates.

Learn this while subscriptions absorb the consequences. Direct API billing, tighter caps, or metered plans will turn invisible waste into an explicit budget, and teams that never measured context will have no baseline for improvement.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Context hygiene is selective memory: preserve what changes the answer, remove what merely records the journey.</p></div>

## Count accepted results

Token counts alone are the wrong target. Run comparable tasks using both policies. Track fresh input, cache reads and writes, output, retries, latency, and review. Define acceptance before the trial: tests pass, requirements hold, no defect appears during the review window.

Then divide total spend, including failed attempts, by accepted results.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Cheap access hides waste. Cost per accepted result reveals whether context hygiene actually improves the work.</p></div>
