On August 1, 2026, engineer [Om Patel](https://x.com/om_patel5/status/2083401185172541449) shared his July usage from [Claude Code](https://code.claude.com/docs/en/costs), Anthropic's coding agent. It showed 6.16 billion tokens: $7,470.35 at retail API prices. His Claude Max subscription cost $200.

That is roughly a 37-fold gap, but name it correctly. The $7,470 was not his bill, and it was not Anthropic's compute cost. It was what identical traffic would have cost through the metered API. What matters most is the customer's exposure to an inefficient habit.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>The subscription hid the meter; it did not erase the traffic.</p></div>

## Flat rates conceal a skill gap

Subscriptions are bargains when heavy usage stays inside a flat fee, but weak teachers. When each turn feels free, engineers have little reason to ask what the agent resends, whether it still belongs, or whether it helps.

The danger appears when caps tighten, work moves to direct API billing, or an enterprise needs defensible unit economics. A team trained only to consume has no answer except model downgrades and blunt limits. Efficiency is now an operating skill the flat rate postponed.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Cheap access can create expensive habits before anyone learns to measure them.</p></div>

## The expensive thing is not the answer

Patel's dashboard assigned $6,440.24—86.2% of the API-equivalent price estimate—to cache reads and writes. [Prompt caching](https://docs.anthropic.com/en/docs/about-claude/pricing) discounts a repeated stable prefix; it does not stop the system from sending that input again. A coding agent may carry instructions, chat history, tool definitions, files, and tool results into every turn.

[Nate B. Jones](https://www.youtube.com/watch?v=Y8vAQ1FgNbM), who sells a context framework, measured 3.77 billion tokens across 143 coding threads in one day; 3.59 billion, about 95%, were reused input. That is one instrumented day, not an industry rate. In 2025, [Manus](https://manus.im/blog/Context-Engineering-for-AI-Agents-Lessons-from-Building-Manus), a production AI agent, reported an average input-to-output ratio near 100:1. The peer-reviewed 2024 [*Lost in the Middle* study](https://aclanthology.org/2024.tacl-1.9/) found that models retrieve relevant information less reliably when it appears in the middle of a long input.

This is context debt: old material keeps charging rent and can obscure today's answer. [Automatic compaction](https://code.claude.com/docs/en/costs) helps, but decides what to preserve and discard for you.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Repeated context can be discounted and still be wasteful, costly, and harmful to retrieval.</p></div>

## Measure the result, not the tokens

Pick one recurring task and run it twice with the same model and settings. First, allow the thread to accumulate. Then start clean and carry only the current artifact, active constraints, relevant decisions, and evidence. Keep tests and reviewer criteria identical.

Record fresh input, cached input, output, latency, API-equivalent cost, test outcome, and reviewer acceptance. Then divide cost by accepted results. A cheaper run that fails review is not efficient; it moved the bill from inference to rework.

Context hygiene decides exactly what the model must see now, retrieve later, or forget. It is deliberate curation, not amnesia. Learn it while subscriptions make mistakes cheap. The meter may return before the habit does.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Context hygiene wins only when it lowers cost per accepted result without lowering acceptance.</p></div>
