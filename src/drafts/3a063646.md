In July 2026, AI practitioner [Om Patel](https://x.com/om_patel5/status/2083401185172541449) paid $200 for Claude Max, the highest-usage subscription tier from AI company Anthropic. His report for Claude Code, Anthropic's command-line coding agent, showed 6.16 billion tokens and an API list-price equivalent of $7,470.35. If he had bought that recorded model mix through Anthropic's public application programming interface, or API, that would have been the bill before any private discounts.

The figure represents retail pricing, not Anthropic's undisclosed compute cost. Its real significance is the missing feedback: a flat subscription can hide expensive behavior so completely that users never learn to correct it. When caps tighten or direct token billing arrives, context efficiency becomes an operating skill.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>The $7,470 figure is an API-price equivalent, not a claim about Anthropic's cost. Flat pricing also removes the signal that would teach users to work more efficiently.</p></div>

## The bill is mostly the past

Patel's report shows that cache reads and writes accounted for 86.2% of the list-price value. A cache write stores input for reuse; a cache read retrieves that stored input at a lower rate. The discount helps, but billions of discounted tokens still add up. Fresh input represented only $14.14, while generated output represented $1,015.97.

AI practitioner [Nate B. Jones](https://www.youtube.com/watch?v=Y8vAQ1FgNbM) found the same pattern in a separate measurement. Across 143 OpenAI Codex coding-agent threads during one working day, 3.59 billion of 3.77 billion tokens were reused input, meaning text sent to the model again. That is 95.2%, or almost 96%. One person's workload cannot establish an industry average, yet [Manus](https://manus.im/blog/Context-Engineering-for-AI-Agents-Lessons-from-Building-Manus), an AI agent service reporting production lessons in 2025, independently put its average input-to-output ratio at about 100 to one.

Each coding-agent turn may carry instructions, tool definitions, conversation history, source files, and logs. Together they fill the context window, the finite body of text available for the next response. Caching lowers the unit price of repetition; it leaves the volume intact.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>The evidence does not prove a universal 96% rate, but independent measurements show the same structure: agentic coding moves far more prior context than newly generated text.</p></div>

## Context hygiene improves cost and judgment

Long context can also reduce quality. [“Lost in the Middle,”](https://arxiv.org/abs/2307.03172) a study released in 2023 and peer-reviewed in 2024, found that language models often performed worse when relevant information sat inside a long input rather than near its beginning or end. More text can make the right evidence harder to use.

Context engineering is the deliberate choice of what an AI agent sees for its current task. Claude Code already uses caching and auto-compaction. Compaction summarizes an old conversation as it nears the context limit, which is useful but selective, and it begins after the thread has already grown.

A better practice starts earlier. Open a clean thread when the objective changes, then carry forward a short working artifact with the goal, constraints, decisions, unresolved failures, and acceptance checks. Supply relevant files and search results instead of the whole discovery trail. Keep stable instructions together, enable only necessary tools, limit oversized logs, and use the least expensive model that passes the same checks.

Context curation can fail when it removes evidence. Preserve what happened and why an attempt failed, while dropping the surrounding chatter. Broad one-shot research is another limit case because wide context may be the work itself.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Good context hygiene preserves decisions and evidence while removing irrelevant history. It can reduce repeated traffic and make the remaining information easier for the model to use.</p></div>

The mapping is narrow: a flat-rate AI interface feels seamless while token accounting continues underneath. Context engineering means seeing and shaping that machinery without giving up the convenience above it.

## Measure what survives review

Cost per token explains an invoice, but it cannot tell us whether the work was worthwhile. The better outcome metric is cost per accepted result: total model cost divided by outputs that pass the relevant tests or review and are kept. Under API billing, use the direct charge. Under a subscription, allocate the seat cost and track the API-price equivalent as an exposure measure.

Support that metric with reused-input share and tokens per accepted result. Compare similar tasks before and after cleaner handoffs, shorter threads, narrower tool access, and model matching. No public controlled benchmark proves that context hygiene always beats switching models, so each team has to measure its own work.

The pricing risk has a precedent. Technology critic [Ed Zitron reported](https://www.wheresyoured.at/the-more-you-buy-the-more-you-lose/) that GitHub Copilot, Microsoft's AI coding assistant, let some power users consume more than 25 times their monthly fee before a move to token billing triggered user revolt.

Instrument one working day now. Record the token mix, the context carried between turns, and which outputs survive review. A flat-rate plan is a cheap place to learn this subtle discipline, but the skill will matter most after the flat rate stops protecting us from our own habits.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Manage AI coding by cost per accepted result, with token mix as a diagnostic. Learning context efficiency now prepares the team for stricter caps and direct billing.</p></div>
