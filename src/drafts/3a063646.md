On August 1, 2026, developer [Om Patel](https://x.com/om_patel5/status/2083401185172541449) posted an unnamed user's July dashboard from Claude Code, Anthropic's terminal-based coding agent. The user paid $200. The dashboard showed 36,881 responses, 6.16 billion tokens, and a total of $7,470.35 at API list prices.

That was 37.4 times the subscription price. It was not the subscriber's invoice, Anthropic's compute cost, or demonstrated waste. The plan included usage subject to limits. The number was counterfactual API-list exposure: what the same traffic would have cost at published API rates. That distinction makes it useful.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>The dashboard exposed a meter the subscription normally blurs. Its value is the question it forces: what produced so much traffic?</p></div>

## What the meter was really showing

Claude Code [sends the full conversation with each request](https://code.claude.com/docs/en/costs) and again with each batch of tool results. That context includes instructions, chat history, tool definitions, files, and prior outputs. Prompt caching discounts unchanged material, but [a cache read still costs one tenth](https://platform.claude.com/docs/en/about-claude/pricing) of ordinary input.

The dashboard's three cache rows accounted for $6,440.24, or 86.2% of its API-list total. That does not make cached context useless; caching is working. It means repeated input dominated the exposure and deserves measurement.

In one instrumented day, [Nate B. Jones](https://www.youtube.com/watch?v=Y8vAQ1FgNbM) reported that 3.59 billion of 3.77 billion tokens in a workspace for OpenAI's Codex coding agent were reused input: 95.2%, or “almost 96%.” Jones sells a context-saving framework; one workspace is not an industry benchmark.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Agentic coding repeatedly carries old text forward. The exact share varies, but the mechanism is normal and the volume can be enormous.</p></div>

## Context hygiene is an engineering skill

Useful context earns its place; irrelevant history competes for attention. The 2024 peer-reviewed study [Lost in the Middle](https://arxiv.org/abs/2307.03172) found that models often use relevant information less reliably when it sits inside long prompts.

Clear threads between unrelated tasks. Retrieve only needed files. Keep stable instructions in a cache-friendly prefix. Cap verbose outputs. Carry decisions, test results, and unresolved errors forward as a compact artifact. Treat automatic compaction as a fallback because a generated summary can omit the exact constraint a later step needs.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Context hygiene preserves useful state while removing accidental history. It can improve both cost and the agent's odds of finding what matters.</p></div>

## Put quality in the denominator

Run a two-week matched test: current practice versus a lean-context policy on comparable tasks, with the same model and blinded acceptance criteria. Log fresh, reused, and output tokens; latency; reviewer minutes; acceptance; and defects.

Calculate cost per accepted result: allocated subscription or API spend plus review labor, divided by accepted results. Adopt only if it falls without a quality regression. The platform team owns the policy, financial operations the ledger, Security or the data protection officer the privacy review, and developers the rollback decision.

Direct API work already exposes the meter subscriptions blur. Learn the discipline while access is cheap, before an API workload turns exposure into spend.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Optimize for accepted work, not token reduction. A cheap subscription is the right place to learn that discipline.</p></div>
