Om Patel paid $200 for a month of Claude Max. His July 2026 [usage report](https://x.com/om_patel5/status/2083401185172541449) valued the same work at $7,470.35 under Anthropic's pay-per-token API prices.

Claude Max is a flat-rate plan from Anthropic, the AI company behind Claude. Patel used it with Claude Code, Anthropic's terminal-based coding agent, and processed 6.16 billion tokens across 36,881 responses. Had the same model mix and cache activity gone through the API, the list-price bill would have been 37.4 times his subscription fee.

That comparison has limits. Anthropic's internal compute cost is undisclosed and lower than its retail API price, while Max plans have rolling five-hour and weekly usage caps. So $7,470.35 is neither Patel's actual bill nor a measure of Anthropic's loss. It is still a useful view of the price signal that a subscription removes.

I think that hidden signal matters more than the discount. When every extra turn appears free, we have little reason to learn why an agent is consuming tokens. Yet Patel's report shows that the main expense was not new code or new reasoning. It was old material moving through the system again.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>A $200 plan concealed $7,470.35 of API-priced activity, but the important gap is educational: flat pricing hides the cost of inefficient agent workflows.</p></div>

## The expensive part was text already sent

An agent cannot continue a task from memory alone. On each model call, its software harness rebuilds a working context from the conversation, instructions, files, tool definitions, and recent results. **Reused input** is the portion sent before, while **prompt caching** lets the provider store a stable prefix and charge less when it appears again.

Less does not mean free. Patel's report attributed $3,595.52 to cache reads and $2,841.89 to cache writes, together 86.2% of the API-priced total. Output cost $1,015.97, while fresh input cost only $14.14. Across all tokens consumed, the workflow moved about 186 input tokens for every output token.

One case cannot establish an industry average, but the shape appears elsewhere. AI practitioner Nate B. Jones [instrumented one working day](https://www.youtube.com/watch?v=Y8vAQ1FgNbM) in Codex, OpenAI's coding agent: 3.59 billion of 3.77 billion tokens were reused input across 143 threads, almost 96%. [Manus](https://manus.im/blog/Context-Engineering-for-AI-Agents-Lessons-from-Building-Manus), a general-purpose AI agent, reported an average input-to-output ratio near 100:1 in production in 2025.

The subscription absorbs this traffic from the user's bill, but it also makes the traffic easy to ignore. Direct API pricing would turn every oversized history and unused tool definition into an immediate engineering decision.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Agentic coding is dominated by repeated input in several heavy-use observations, and caching discounts that repetition without eliminating its cost.</p></div>

## Context is also a quality budget

A model's **context window** is the text it can consider during one call. Filling that window with old logs, abandoned approaches, and unrelated instructions does more than raise the bill: it makes the useful evidence harder to retrieve and leaves conflicting directions in play.

This problem predates today's coding agents. In *Lost in the Middle*, a 2023 Stanford and Berkeley study published in the journal *Transactions of the Association for Computational Linguistics* in 2024, researchers found that language-model performance often fell when relevant information sat inside a long context rather than near its beginning or end. More capacity did not guarantee reliable use of everything inside it.

**Context engineering** is the deliberate choice of what information an agent receives, how it is arranged, and what survives into the next turn. Claude Code already uses caching and automatic compaction, which summarizes a thread as it approaches its limit. Those defaults help, but a summary chosen on the fly may preserve the discussion and lose the decision, test result, or constraint that the next step needs.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Repeated context is a quality problem as well as a billing problem, so the useful skill is deciding what the next model call actually needs.</p></div>

The mapping to agentic coding is narrow: every model call starts another loop, and the harness restores state by sending context again. Unlike the film's hero, the agent pays in tokens for every replay, so the goal is to preserve the learning without replaying the entire battle.

## Learn while the subscription carries the cost

The answer is not to abandon subscriptions simply to feel the meter. Keep the favorable plan, but instrument the workflow as if every token reached an API invoice. Track fresh input, cache reads, cache writes, output, and whether the result passed its test or review.

Then reduce context with intent. Start a clean thread when the objective changes. Carry forward the accepted artifact, current constraints, changed files, test evidence, and unresolved questions rather than the full debate that produced them. Search for relevant files before loading them, remove tool definitions the task cannot use, keep stable instructions in a cacheable prefix, cap unnecessary output, and choose the least expensive model that still passes the required check.

The governing metric is **cost per accepted result**: total model cost divided by outputs that survive review and can be used. Token cost alone rewards cheap failures; acceptance connects efficiency to delivered work. It also reveals whether trimming context genuinely helps or merely causes more retries.

Flat-rate access may remain generous, but engineers should not build their habits around that assumption. GitHub Copilot, the subscription coding assistant, previously let some power users consume [more than 25 times their monthly fee](https://www.wheresyoured.at/the-more-you-buy-the-more-you-lose/) before token-based billing arrived and users revolted. Claude's future pricing may develop differently. The prudent move is to learn context engineering while inefficient experiments still cost $200, rather than after the same behavior appears as a $7,470 invoice.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Use the subscription as a training window: curate context, measure accepted outcomes, and build efficient habits before a vendor's pricing makes those habits urgent.</p></div>
