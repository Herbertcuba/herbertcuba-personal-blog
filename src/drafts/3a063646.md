On August 1, 2026, engineer [Om Patel](https://x.com/om_patel5/status/2083401185172541449) shared a Claude Code usage screen. He paid $200 for Anthropic’s Max subscription. Claude Code, Anthropic’s coding agent, had processed 6.16 billion tokens. At [standard API list prices](https://docs.anthropic.com/en/docs/about-claude/pricing), the screen priced that activity at $7,470.35, or 37.4 times his fee.

The $7,470 was neither Patel’s bill nor Anthropic’s compute cost. It was a retail-price estimate of activity. The gap exposes what flat pricing lets us ignore: coding agents can move enormous amounts of old text without teaching us to ask why.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>The screenshot does not reveal a secret bill. It reveals an efficiency signal hidden by flat pricing.</p></div>

## Every new request carries the old thread

An agent’s context is its working state: instructions, conversation history, tool definitions, files, and results. Much of that state returns to the model each turn. Prompt caching discounts exact repetition. A cache write stores a reusable prefix; a read reuses it. Anthropic prices reads at one-tenth of ordinary input, but discounted repetition remains traffic.

Patel’s screen attributed $6,440.24, or 86.2% of its estimate, to cache reads and writes. Separately, engineer [Nate B. Jones](https://www.youtube.com/watch?v=Y8vAQ1FgNbM) measured 3.59 billion reused tokens out of 3.77 billion across 143 coding threads in one day—almost 96%. That workspace is not an industry rate, but it exposes the mechanism: small requests sit beside huge histories.

Long context also weakens retrieval. The peer-reviewed 2024 study [“Lost in the Middle”](https://aclanthology.org/2024.tacl-1.9/) found less reliable use of information buried inside long inputs. The waste can arrive twice: more traffic and less dependable attention.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Most traffic may be working state the model has already seen, and keeping more of it can reduce both efficiency and recall.</p></div>

## Learn the skill before the subsidy moves

Claude Code [automatically compacts long threads](https://code.claude.com/docs/en/costs) near the context limit. Useful, but the harness chooses what to forget. Context hygiene means controlling the working state. Start unrelated work in a clean thread. Carry accepted requirements, decisions, and test results forward as a compact artifact, not the debate behind them. Retrieve files on demand, remove unused tools, cap verbose output, and keep stable instructions together for caching.

Test the practice instead of assuming it helps. Run the same task set twice with one model: baseline, then hygiene. Fix acceptance tests first. Record API-priced input, cache writes, cache reads, output, latency, and accepted results. Divide total measured spend by passing results. Fewer tokens matter only when the work still clears the bar.

Direct API billing exposes the meter; a flat subscription muffles it. That visibility has an overlooked benefit: teams learn where their context goes and how to reduce it safely before a pricing change makes the lesson urgent. [GitHub Copilot](https://www.wheresyoured.at/the-more-you-buy-the-more-you-lose/) showed how fast a generous plan can change: power users consumed more than 25 times their fee before token billing arrived. The $7,470 estimate does not predict Anthropic’s next price. It warns us not to turn today’s plan into tomorrow’s operating assumption.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Context hygiene is preparation for repricing, measured as cost per accepted result.</p></div>
