On August 1, 2026, AI practitioner Om Patel [shared a third-party dashboard](https://x.com/om_patel5/status/2083401185172541449) for an unnamed user's July activity in Claude Code, the coding assistant made by AI company Anthropic. It counted 36,881 responses and 6.16 billion tokens. Had the same token mix been bought through Anthropic's application programming interface, or API, at posted prices, it would have cost $7,470.35. The user paid $200 for a Claude Max subscription.

That is 37.4 times the subscription fee. The larger number is API list-price exposure: a reconstruction of what identical use would cost under direct token billing. It is neither an invoice nor Anthropic's undisclosed compute cost. Without the subscription, and without changing the workflow, this month would have been radically more expensive.

My concern is the habit hidden inside the bargain. Within its limits, a flat plan hides the marginal price of another request, so teams have little reason to learn which context their agents need. That lesson becomes harder to defer when limits tighten or work moves to direct billing.

<span class="chapter-tldr__label">In short</span>
<p>The subscription cuts the bill while hiding the signal that would teach a team to run its coding agents efficiently.</p>

## Most of the exposure sits in the context

Anthropic's [Claude Code cost documentation](https://code.claude.com/docs/en/costs) says the tool sends the full conversation with every request and may send additional requests carrying batches of tool results. Old instructions, prior messages, file contents, logs, and tool definitions therefore return. That material is called reused input when it appears in later requests.

Prompt caching lets the provider reuse computation for an unchanged opening block, making repetition cheaper and faster. It does not make repetition free under API pricing. In Patel's dashboard, the rounded list-price split was 86.2% for cache reads and writes, 13.6% for generated output, and about 0.2% for fresh input.

A separate observation points in the same direction. In a video published on July 29, 2026, practitioner and framework seller Nate B. Jones [reported](https://www.youtube.com/watch?v=Y8vAQ1FgNbM) that his local tracker labeled 3.59 billion of 3.77 billion tokens as reused input during one working day across 143 threads in Codex, OpenAI's coding-agent environment. That is almost 96%, but it is one self-reported workspace rather than an audited industry rate. Reused input can be essential, so the label is a reason to inspect the traffic rather than proof of waste.

<span class="chapter-tldr__label">In short</span>
<p>Coding agents repeatedly carry their history forward. Caching discounts that traffic, while the bounded 86% and almost-96% observations show why it deserves measurement.</p>

## Context engineering is selective memory

Context engineering means deciding which instructions, evidence, history, and tool descriptions enter each model request. Context hygiene is the daily practice of keeping that package current without losing the evidence needed to audit a result.

Simply cutting tokens can make an agent cheaper and worse. *Lost in the Middle*, a [2024 peer-reviewed paper](https://arxiv.org/abs/2307.03172) by Nelson Liu and colleagues, found that models can struggle to use relevant information buried inside long inputs. Yet removing the wrong test failure or design constraint creates a different problem. The goal is controlled selection:

- Start a new thread when the objective changes.
- Carry a short artifact with the current specification, decisions, evidence, and open risks instead of the full debate.
- Retrieve narrow file sections and cap log output rather than pasting whole repositories or command histories.
- Load only the required tools, while keeping stable instructions together so prompt caching can work.

Automatic compaction summarizes a conversation near its context limit and is a useful safety net. It cannot know which detail a reviewer will consider decisive, so the team still owns the boundary.

<div class="chapter-tldr">
<span class="chapter-tldr__label">In short</span>
<p>Context hygiene preserves verified state while dropping stale process. The target is the smallest evidence package that can still produce and explain a correct result.</p>
</div>

## Measure what survives review

Begin with a shadow replay rather than a live rollout. Select ten previously accepted tasks before inspecting their token traces, then run each once with the current context policy and once with the lean policy in randomized order. Freeze the model version, tools, repository state, task specification, and checks. An accepted result passes those checks, receives the named reviewer's approval, and survives the agreed rollback period.

| Trial field | Record before you start |
| --- | --- |
| Traffic | Uncached input, cache reads and writes, output, tool-result size, latency, and retries |
| Quality | Test outcome, reviewer time, rework, acceptance, and rollback |
| Decision | Minimum improvement threshold, review date, and named authority to scale, stop, or restore |

A useful screening gate is at least 25% lower cost or list-price exposure per accepted result, no fewer accepted results than the baseline, reviewer time no more than 10% higher, and zero critical regressions, meaning failures that block release or force a rollback. These are policy defaults, not research findings. A pass earns a larger live sample, not automatic deployment.

Keep two calculations separate. Cash cost per accepted result uses billable API charges or a documented share of the subscription fee, plus review and rework cost, divided by accepted results. For a shared seat, allocate the fee by measured active-agent time and keep that basis fixed. API list-price exposure per accepted result uses the reconstructed token value divided by accepted results. Never add exposure to cash spend.

Cleaner context may not reduce today's flat invoice. It can still reduce latency, delay plan limits, and teach the team how its agent works. Learn that skill before every request is billed directly, and a future model, contract, or context change can be judged without guessing.

<span class="chapter-tldr__label">In short</span>
<p>Judge context changes by cost per accepted result, with quality and rollback visible. Build the discipline while the subscription still cushions the lesson.</p>
