On August 1, 2026, engineer Om Patel [shared a usage screen](https://x.com/om_patel5/status/2083401185172541449) from Claude Code, Anthropic's coding agent. It showed 6.16 billion tokens, which would have cost $7,470.35 at [standard API list prices](https://docs.anthropic.com/en/docs/about-claude/pricing). His subscription cost $200: a 37.4-fold gap.

That $7,470 was not his bill, and it was not Anthropic's compute cost. It was a retail API-price estimate. That distinction is the point. Flat pricing hides the consequences of how we use AI. An API meter makes inefficient requests visible; a subscription can let the habit mature unnoticed.

The risk is not a surprise invoice tomorrow. It is reaching a repricing, usage cap, or enterprise rollout without having learned how to control the workload.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>The generous subscription buys us time to learn efficiency before the market makes efficiency mandatory.</p></div>

## The expensive part is what the agent remembers

A model does not retain yesterday's thread on its own. A coding agent rebuilds that context for every request: system instructions, conversation history, tool definitions, files, and tool results. As the thread grows, each new instruction travels with more old material.

Prompt caching makes a stable prefix cheaper to reuse; it discounts repetition rather than eliminating it. On Patel's screen, cache reads and writes represented $6,440.24, or 86.2% of the API-price estimate. In one instrumented day, engineer Nate B. Jones, who sells a context-management framework, [reported](https://www.youtube.com/watch?v=Y8vAQ1FgNbM) 3.59 billion reused tokens out of 3.77 billion across 143 coding threads—almost 96%. That is one workspace, not an industry rate, but it exposes the same mechanism.

More context can also reduce reliability. The peer-reviewed 2024 [“Lost in the Middle” study](https://aclanthology.org/2024.tacl-1.9/) found that models used relevant information less reliably when it sat inside long inputs. Long inputs can therefore raise the meter while lowering the odds that the model notices what matters.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Context is not free memory. Repeated material remains traffic even when caching discounts it, and excess context can make evidence harder to find.</p></div>

## Make subscriptions fund the experiment

Treat flat pricing as a laboratory, not an operating assumption. Choose a recurring task, write its acceptance tests first, and hold the model and settings constant. Measure current behavior. Then repeat under a strict context budget.

On the second pass, open a new session at task boundaries. Record settled decisions in a short handoff note. Load files just in time, remove unused tool definitions, and request bounded responses. Claude Code already [compacts long threads automatically](https://code.claude.com/docs/en/costs), but automatic summaries have their own retention policy. Context hygiene means choosing the agent's working set deliberately.

Record fresh input, cache reads, cache writes, output, latency, and accepted results. Divide the API-equivalent total by the number accepted. A cheap failure is still waste; so is an expensive answer nobody needs. The winning run has the lowest cost per accepted result without relaxing the test.

Use today's flat price to build tomorrow's competence.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>A flat fee should finance better engineering, not conceal unexamined context. Build context discipline now, and judge it by total cost per accepted result.</p></div>
