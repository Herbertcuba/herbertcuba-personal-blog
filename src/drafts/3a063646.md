On August 1, 2026, engineer Om Patel shared a usage screen from Claude Code, Anthropic’s coding agent. It showed 6.16 billion tokens and $7,470.35 at retail API prices for July 2026, covered by his $200 Claude Max subscription. That larger number was neither his bill nor Anthropic’s compute cost. It was a translation: what the same traffic would have cost through the metered API.

The translation matters because flat pricing can hide the skill we will need when prices, caps, or workloads change: using context deliberately.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>The subscription did not cost $7,470. It concealed a 37-fold API-price exposure and an efficiency lesson.</p></div>

## The bill is mostly yesterday’s prompt

Patel’s screen separates the traffic. Cache reads and writes accounted for $6,440.24, or 86.2% of the API-price estimate. Prompt caching stores a stable prefix so repeated input is cheaper to process; it does not make that input disappear. The blended cache-read price was about $0.61 per million tokens, consistent with the models shown.

Direct API billing exposes each choice; a subscription hides it. Missing feedback is the subscription’s hidden cost. Resending an oversized tool catalog, an old debugging trail, or half a repository feels free even when it dominates the underlying traffic.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>The visible output is not the main load. Most of this API-price exposure came from carrying old context forward.</p></div>

## Reuse becomes context debt

Every agent turn can resend system instructions, conversation history, tool definitions, files, and tool results. In one instrumented day, Nate B. Jones recorded 3.77 billion tokens across 143 coding threads; 3.59 billion, about 95%, were reused input. Jones sells a context framework, so the exact percentage needs an n=1 caveat. Yet the mechanism appears elsewhere: Manus, a production AI agent, reported about 100 input tokens for each output token in production.

Volume is only half the problem. The peer-reviewed 2024 “Lost in the Middle” study found that models retrieve relevant information less reliably when it sits inside long inputs. Context can therefore raise cost while lowering the odds of a correct answer.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Repeated context is not free memory. It is paid traffic and, eventually, retrieval noise.</p></div>

## Make the subscription fund the experiment

Context hygiene means choosing what the agent may carry. Test it on a recurring task. Hold model and settings constant, then run twice: with the accumulated thread and with a curated working set. Open a new thread; carry the artifact and decisions, not the debate; retrieve relevant files; prune unused tools; cap output; keep stable instructions cacheable.

Record task ID, fresh input, cache reads and writes, output, latency, test result, reviewer decision, and API-equivalent cost. The lean run wins only if the same tests pass and reviewer acceptance meets an agreed tolerance. Automatic compaction decides what to preserve and discard for you.

Then divide cost by accepted results. That denominator prevents a cheap failed run from looking efficient.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Use flat pricing as a training window. The durable advantage is lower cost per accepted result without a quality regression.</p></div>
