AI engineering is moving fast enough that one abstraction can reach production before teams understand the failure created by the last. On July 25, 2026, engineer Jonas Risbrandt [summed up the progression](https://www.linkedin.com/posts/jonas-risbrandt-8309263_i-find-the-evolution-of-agentic-coding-slightly-activity-7485292345890865152-xymz): “Then we realized one prompt was not enough, so we added loops. Then loops were not enough, so we introduced graphs. Now we are adding typed state, control flow, persistence, retries, error handling, observability, reusable components, and testing.” His punchline was, “Haven't we just invented... a programming language?”

A day earlier, Anthropic, the AI company behind Claude, [released Claude Opus 5](https://www.anthropic.com/news/claude-opus-5). Anthropic called it its “most aligned model to date” after an automated behavioral audit before deployment. The discussion on [Hacker News](https://news.ycombinator.com/item?id=49038433), a technology news forum, drew over 1,700 upvotes. That attention is not proof of safety. It shows how much hope still sits at the model layer.

Typed state addresses the production layer. It declares what an agent system may know at each step, validates changes, and saves the result so a team can reconstruct what happened.

## Follow one card through four architectures

Consider a content engine run by Hermes CLI command-line agent workers: ideator, researcher, writer, slop-reviewer, fact-checker, persona-panel, visual-designer, and publisher. Its cards move through twelve statuses in `content_engine.tasks`, a table in Postgres, an open-source relational database.

**Prompt.** A prompt is the natural-language instruction sent to a model:

```text
Research this idea, write it, review and fact-check it, then publish.
Ask a human when uncertain.
```

Every incident adds another instruction until the prompt is wearing a toolbelt. It describes the stages but cannot prove which evidence the writer held when a card moved to `slop_review`.

**Loop.** ReAct, short for Reason plus Act, is a 2022 agent pattern in which a model chooses an action, observes the tool result, and repeats:

```python
while not done:
    action = model(context)
    context.append(run(action))
```

The message history now doubles as state. This article’s task history contains the failure: an exact Hacker News count was corrected to “over 1,700,” then stale context restored an exact value. Both appeared as ordinary messages, so recovering the agent’s belief required transcript archaeology.

**Graph.** LangGraph is a library for arranging language-model work as nodes and routes. Its `StateGraph` builder exposes control flow; `MessagesState` supplies a state shape centered on accumulated messages:

```python
graph = StateGraph(MessagesState)
graph.add_edge("draft", "slop_review")
graph.add_conditional_edges("fact_check", route_by_verdict)
```

LangGraph supports custom typed schemas, so graphs do not have to be untyped. Yet a visible route can still enter a node containing a prompt, a loop, and mutable message history. The map is inspectable while the cargo is not.

**Typed state.** `TypedDict` declares the keys and value types a Python dictionary should contain; `Literal` restricts a field to named values:

```python
Status = Literal[
    "ideas_inbox", "approved", "research", "draft", "slop_review",
    "fact_check", "persona_panel", "design", "human_approval",
    "publish", "done", "escalated"
]
class CardState(TypedDict):
    status: Status
    brief_version: str
    sources_verified: bool
    hn_points_label: Literal["over 1,700"]

def move(state, target):
    if target == "publish" and not state["sources_verified"]:
        raise IllegalTransition
    persist_snapshot(state, target)
```

`TypedDict` helps static checking but does not enforce runtime values, so validation must also run when state changes. The publish attempt can then fail loudly, while each transition stores the brief version, source artifacts, verification flags, worker, and time. “What did the writer know?” becomes a database query instead of an interpretation of a chat log.

<span class="chapter-tldr__label">In short</span>
<p>Prompts describe work, loops accumulate context, and graphs expose routes; typed and validated snapshots expose the state crossing each route.</p>

## Put one consequential transition under contract

Types do not make an agent correct. They move malformed or forbidden changes to a boundary where the system can reject them. Strong typing is one of software’s oldest craft disciplines. Ruby on Rails 1.0, the web framework released in December 2005, made a related move by treating database schemas and migrations as versioned contracts.

In March 2025, Inngest AgentKit, a TypeScript framework for AI agents, described its routing as a fully typed state machine. LangGraph also supports shared state schemas. These examples show independent teams moving in the same direction, not broad adoption.

The distinction separates model alignment from system accountability. Anthropic’s pre-deployment audit can test how Opus 5 tends to behave, but it cannot show what a particular production run knew or changed. Calling the model aligned while leaving workflow state illegible is alignment theater. A legible [AI operating model](/posts/building-the-ai-operating-model/) needs behavioral evaluation and inspectable execution records.

On Monday, put one consequential transition, such as `human_approval → publish`, under an engineer’s ownership. Define its required fields, persist before-and-after snapshots in Postgres, reject missing evidence at runtime, and test rollback. That boundary exposes [verification debt](/posts/2026-03-09-verification-debt-crisis/), the gap between generated output and proof, while making [reversibility](/posts/reversibility-is-the-new-correctness/) a property of stored state rather than a request buried in a prompt.

Risbrandt wrote, “We replaced the code with a prompt, and then slowly started reintroducing the code around the prompt.” I think that code is returning for a good reason. The model may remain probabilistic; the system around it must be knowable.

<span class="chapter-tldr__label">In short</span>
<p>Do not begin with a platform rewrite: contract one high-consequence transition so failure, ownership, evidence, and rollback become explicit.</p>
</div>
