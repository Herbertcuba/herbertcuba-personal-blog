By August 2026, [OpenClaw’s GitHub repository](https://github.com/openclaw/openclaw) still had hundreds of thousands of stars. Yet BetterWay, a YouTube channel, was already asking [“What Happened To OpenClaw?”](https://youtu.be/moRJqv1z6ww?is=NVS3vjDxPFuWwxzP), as though the ending were known. That contrast reveals a measurement problem.

GitHub is a platform where software projects publish code. Its [star](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars) is a way to save or show interest in a project. A star can be removed, but the total is not a measure of active use. It cannot tell us who installed OpenClaw, who kept using it, who paid for it, or where anyone went next.

The public sources used for this article do not show how many people kept using OpenClaw, so I do not think we can say it died. We can make a narrower and more useful claim: it made broad interest in action-taking AI visible at unusual scale. That is category validation, evidence that people care about a kind of product. It is not yet category capture, which means one product has turned that interest into lasting use.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>OpenClaw drew extraordinary public attention, but GitHub stars cannot prove active use or retention. The evidence supports category validation, not an obituary or a final winner.</p></div>

## Why OpenClaw drew so much attention

Peter Steinberger, an Austrian software developer, created the repository in November 2025. OpenClaw’s [official history](https://github.com/openclaw/openclaw/blob/main/docs/start/lore.md) records two quick name changes in late January 2026: Clawdbot became Moltbot, which then became OpenClaw.

OpenClaw describes itself as a [self-hosted gateway](https://docs.openclaw.ai/llms.txt), meaning software that a person runs on their own computer to connect an AI model with messaging apps and tools. A user could send instructions through WhatsApp or Telegram while the system [controlled a browser](https://docs.openclaw.ai/tools/browser), [ran shell commands](https://docs.openclaw.ai/tools/exec) that could change files or start programs, and [tracked work in the background](https://docs.openclaw.ai/automation/tasks). An AI agent is software that uses tools to pursue a goal instead of stopping after it writes an answer.

OpenClaw did not invent computer-using AI. In October 2024, Anthropic, the AI company behind the Claude model family, introduced [computer use](https://www.anthropic.com/news/3-5-models-and-computer-use), which let a model inspect a screen, move a cursor, click, and type. OpenClaw made a particular bundle easy to see: local operation, familiar messaging, broad tool access, and background work. The scale of the response made that bundle hard for the market to dismiss.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>OpenClaw brought local control, everyday messaging, and real tool use into one clear product idea. That combination, rather than action alone, explains why it became such a strong market signal.</p></div>

## Acting is harder than answering

The same access that made OpenClaw useful also raised the cost of mistakes. One [GitHub security advisory](https://github.com/advisories/GHSA-g55j-c2v4-pjcg), a public notice about a software weakness and its fix, reported that a program on the same computer could change gateway settings without first proving it was allowed to connect. It could then run commands with the user’s permissions. The flaw was fixed. The advisory does not prove a breach or a broad enterprise ban, but it shows why software with command access needs stronger controls than a chatbot.

A self-hosted agent also depends on the companies that supply its AI models. [Anthropic’s consumer terms](https://www.anthropic.com/legal/consumer-terms) allow automated access through an API key, a credential that software uses to call the model service, or with explicit permission. Its [API pricing](https://platform.claude.com/docs/en/about-claude/pricing) charges for the text the model processes and produces. This does not prove one universal OpenClaw cutoff or price increase. It shows that running an agent on your own machine does not remove outside rules and costs.

Fast growth adds maintenance pressure. The August research snapshot for this article found a large queue of reported problems and proposed code changes. It also showed maintainers accepting changes at a high rate. A pull request is a proposed change that maintainers must review before it enters the project. The evidence supports a heavy review burden, not a story in which the maintainers stopped working or the queue caused a specific security flaw.

In February 2026, Steinberger said he was [joining OpenAI](https://steipete.me/posts/2026/openclaw), the company behind ChatGPT, and that OpenClaw would move to a foundation. His current [profile](https://steipete.me/about) says the independent OpenClaw Foundation now stewards the project. That is an organizational change, not evidence that OpenAI bought OpenClaw or that users left it.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Delegated action brings security, provider, and maintenance work with it. OpenClaw faced real pressure, but the public record shows active maintenance rather than a simple collapse.</p></div>

## When action becomes the baseline

The ability to act is no longer unique. [OpenAI’s ChatGPT agent](https://openai.com/index/introducing-chatgpt-agent/) uses a virtual computer run by the provider to navigate websites and execute code. [Hermes Agent](https://github.com/NousResearch/hermes-agent), an open-source project from AI research company Nous Research, documents browser and command-line tools, [memory that keeps information between sessions](https://hermes-agent.nousresearch.com/docs/user-guide/features/memory), and reusable procedures called [skills](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills).

These overlapping features show that several products can now offer action. They do not show that OpenClaw users moved to Hermes, that one system is safer, or that competitors copied OpenClaw. A managed agent runs on a vendor’s infrastructure. That can reduce local setup, but it asks the user to trust the vendor with data and with keeping the service available. A self-hosted agent gives the operator more direct control while leaving more of the daily work with that operator.

Once action becomes normal, it stops being a durable edge. A durable edge is an advantage that survives changing models and repeated use. It must appear in work that people accept, fewer corrections, clear limits on what the agent may do, reliable recovery after failure, and a total cost the user can sustain.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Action is becoming a basic feature of the category. Lasting differences will come from useful results, control, recovery, and cost rather than from the ability to act by itself.</p></div>

## What category capture would look like

Category capture needs evidence from repeated work. A simple test is to choose a small set of recurring tasks, compare the agent with the current way of doing them, keep its permissions fixed, and count every attempt. Measure how many results people can use without fixing them, how often a person must step in, how serious the failures are, and what the full process costs. Set the stop rules before the test begins.

One result matters more than launch attention: do people keep using the product after the novelty fades? If action-taking agents fail to improve recurring work, or if people stop using them once the demonstrations end, that would weaken the claim that the market demand is lasting. If use continues under clear limits and sustainable costs, a product is moving from category validation toward category capture.

OpenClaw’s most important contribution may be that it made the appetite for delegated action hard to ignore. It gave the market a large, visible signal while many vendors were expanding agent capabilities. But the project that reveals a market is not automatically the one that will serve it best. Category validation and category capture are different jobs.

<div class="chapter-tldr"><span class="chapter-tldr__label">In short</span><p>Lasting leadership has to show up in repeated useful work under clear controls and sustainable costs. OpenClaw proved the category mattered; which product captures it remains open.</p></div>
